# Affiliate Promo Decision Platform

Инструмент для принятия решения: с каким партнёром (Yandex / Arbuz.kz / Wolt / Magnum)
и какой промо-механикой запускать акцию "Купи Samsung — получи бонус", сколько это будет
стоить и какой ожидается результат. Полностью локально, офлайн, без передачи данных наружу —
это не пожелание, а архитектурное решение с самого начала.

## Что внутри

Один файл — `index.html`. Открывается двойным кликом, без установки, без сервера, без
интернета. Все библиотеки (Excel, PowerPoint) встроены прямо в файл.

**7 модулей, один пересчёт тянет за собой все остальные:**

1. **Данные и допущения** — SKU, ритейлеры, период; импорт своего Excel/CSV
2. **Budget & Promo Simulator** — вся юнит-экономика акции (см. `FORMULAS.md`)
3. **Partner Scoring** — прозрачное сравнение 4 партнёров по 8 весовым критериям,
   каждый балл — с объяснением
4. **Kaspi Opportunity** — отдельная оценка канала: Include / Test / Phase 2 / Do Not Include,
   с явной причиной
5. **Финальное решение** — сводит всё в одну таблицу: что запускать, почему, сколько, риски
6. **Landing Preview** — превью лендинга под выбранный сценарий, можно скачать как HTML
7. **Бонус: медиаплан** — распределение digital-бюджета по каналам + идеи усиления,
   привязанные к текущему сценарию

## Как запустить

Просто открой `index.html` в браузере (любой современный браузер — Chrome/Edge/Firefox).
Ничего устанавливать не нужно, сервер не нужен, интернет не нужен.

Чтобы прогнать на своих данных — вкладка 1 → "Загрузить Excel/CSV с продажами", или правь
таблицы SKU/ритейлеров прямо в интерфейсе.

## Экспорт

- **Excel** — 8 листов: Assumptions, Sales & SKU Mix, Full Budget, Partner Comparison,
  Simulation, Kaspi Opportunity, Final Recommendation, Media Plan & Ideas
- **PowerPoint** — 2 слайда на английском для руководства (Recommendation + Key Metrics)
- **Landing HTML** — отдельный файл превью лендинга

## Офлайн и конфиденциальность

Все расчёты (юнит-экономика, scoring, рекомендации) выполняются в браузере, локально.
Ни один запрос никуда не уходит — библиотеки для Excel/PowerPoint встроены в файл, а не
подгружаются с CDN. Данные о продажах/бюджетах не покидают компьютер, на котором открыт файл.

## Прозрачность рекомендаций

По условию задания — никакого "чёрного ящика" и случайных ИИ-ответов. Каждая рекомендация
прослеживается до конкретной формулы или правила:
- Partner Scoring — явные веса × баллы, с объяснением каждого балла
- Promo Mechanics — жёстко привязаны к атрибутам партнёра, не сгенерированы на лету
- Kaspi-решение — дерево правил с видимой причиной (см. `index.html`, функция `computeKaspiOpportunity`)
- Confidence и риски на финальном экране — вычисляются из фактических цифр модели,
  не проставлены вручную

Полная спецификация формул юнит-экономики — в `FORMULAS.md`.

## Использованные инструменты

- **Claude** — вся архитектура, формулы, промпт-инжиниринг структуры решений
- **SheetJS (xlsx)** — импорт/экспорт Excel, встроен в файл
- **PptxGenJS** — экспорт PowerPoint, встроен в файл
- Vanilla HTML/CSS/JS — весь интерфейс, без фреймворков и без сборки

## Ограничения текущей версии (MVP)

- Демо-допущения (Sales Uplift 15%, Registration Rate 30%) — явно помечены как редактируемый
  Base Demo Scenario, не бенчмарк Samsung
- Логотипы партнёров — не включены, используются текстовые бейджи
- Данные о продажах Kaspi.kz — ручной ввод маркетолога (нет исторических данных, как и
  указано в задании)
